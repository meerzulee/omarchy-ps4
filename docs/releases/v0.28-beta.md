# Omarchy PS4 Manager v0.28 beta

This is a private hardware-development beta for jailbroken PS4 consoles. It is
not a production release and does not provide a jailbreak.

## Hardware evidence

One bounded test on the project PS4 Slim Baikal B1 passed the v0.28 boot path:

- verified all four embedded and internal boot-set artifacts;
- treated the already-current internal set as a no-op;
- sent the 320,936-byte Linux loader in one complete write;
- booted Linux `6.18.44-ps4-baikal` with the 1024 MB VRAM profile;
- resolved the external whole-device ext4 root labelled `OMARCHY-PS4`;
- kept PS4 internal SATA outside the supported Linux root path;
- showed the quiet Omarchy splash and reached the desktop after manual login.

The exact hardware records are `EXP-20260823-018-A10` and
`EXP-20260823-018-A11` in `experiments/SESSIONS.md`.

## Requirements

- a jailbroken PS4 with GoldHEN and BinLoader available;
- the matching flashed Omarchy PS4 USB connected before launch;
- the currently tested Baikal B1 profile; other southbridges are unverified.

## Known limitations

- Persistent LightDM autologin is not accepted: the effective configuration
  and PAM group are present, but the greeter still appears. Manual login works.
- The PS4 exposes no usable RTC. New gift images enable
  `systemd-timesyncd`; an existing development USB can enable it once with
  `sudo timedatectl set-ntp true`.
- This is one successful boot-path run, not repeated cold-boot acceptance.
- Signed update manifests, manual restore and diagnostics export remain future
  work.

## Publication gate

Keep this GitHub release as a draft. The embedded PS4 Linux Loader has no
declared repository-wide license, and the selected upstream wallpaper files
lack complete per-file redistribution provenance. Publishing the binary is a
separate project-owner rights decision after those inputs are replaced or
cleared.
