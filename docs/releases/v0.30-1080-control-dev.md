## Recovery topology

1. Orbis and GoldHEN provide the FPKG runtime, FTP development access and the
   local loader handoff.
2. The FPKG manages the kernel, initramfs, boot arguments and VRAM setting in
   console app storage under `/data/linux/boot`.
3. The external USB contains the complete Omarchy root filesystem and matching
   kernel modules.
4. The failed ultrawide boot files and the older legacy set remain separate,
   recoverable directories; v0.30 does not delete either one.
