# Quattro wallpaper sources

Status: private FPKG prototype inputs. These files are not cleared for public
redistribution.

The selected files come from the official `basecamp/omarchy` v4.0.0 commit
`f0020448ca87329199de7cb12f2015ebc4a3e5e7`. Their bytes are unchanged from
the previously reviewed Quattro source pin, checked on 2026-08-14.

The build center-crops each source to 1920x1080, applies the corresponding
theme overlay, strips metadata and stores an 84-quality JPEG in `/app0`.
The upstream repository has an MIT license, but these image files have no
per-file license or complete creator provenance. Do not publish the resulting
FPKG until every image has passed a separate rights review.

`themes/tokyo-night/backgrounds/1-quattro.jpg` is deliberately excluded
because it prominently contains Audi/quattro, Castrol and Michelin marks.
